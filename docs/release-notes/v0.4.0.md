The applet now runs your schedule by itself, so nothing needs to run in the background.

> ⚠️ **Changed:** the **Start on login** toggle is gone, since the applet now does that job. Upgrading removes the old autostart entry. If you don't want the applet on your panel, run `systemctl --user enable --now cosmic-nightlight.service` instead.

### New
- **Schedule to the minute.** **From** and **To** now take hours and minutes (12- or 24-hour, following your COSMIC setting), and the **Schedule** row shows the result, e.g. *Warm from 9:30PM to 6:00AM*. Your old settings carry over.
- **Brightness slider.** Dims the screen while the night light is on, down to 50%.
- **No background service needed.** The applet checks the clock every 15 seconds and updates the screen when your schedule says to.

### Fixed
- **Daytime schedules work.** A schedule like `9:00AM` → `5:00PM` used to stay on all day and night.
- **The tint comes back after suspend.** Before, it stayed off until the next scheduled change.
- **No more freezing** when you flip the toggle or drag a slider.
- **One flicker per change, not several.**
- **Sliders no longer jump** while you're dragging them.
- `uninstall.sh` now fully removes the systemd service.

### Other
- The settings window opens tall enough to show everything without scrolling.

**Full changelog:** https://github.com/danielcwtts/cosmic-nightlight/compare/v0.3.1...v0.4.0

## Install

1. Download **`cosmic-nightlight_0.4.0-1_amd64.deb`** from the Assets section below.
2. Open it with the **COSMIC Store** and click **Install**
   (or run `sudo apt install ./cosmic-nightlight_0.4.0-1_amd64.deb`).
3. Add the applet: **COSMIC Settings → Desktop → Panel** (or **Dock**) **→ Configure applets → Add applet → Night Light**.
