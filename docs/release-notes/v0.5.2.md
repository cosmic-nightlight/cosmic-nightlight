This release makes it easier to get your schedule running.

### New
- **Add to Panel now adds the applet for you.** The button in the "Your schedule isn't running" notice puts Night Light on your panel in one click, instead of sending you to COSMIC Settings to do it.

**Full changelog:** https://github.com/cosmic-nightlight/cosmic-nightlight/compare/v0.5.1...v0.5.2

## Install

1. Download **`cosmic-nightlight_0.5.2-1_amd64.deb`** from the Assets section below.
2. Open it with the **COSMIC Store** and click **Install**
   (or run `sudo apt install ./cosmic-nightlight_0.5.2-1_amd64.deb`).
3. Add the applet: **COSMIC Settings → Desktop → Panel** (or **Dock**) **→ Configure applets → Add applet → Night Light**.

**Flatpak (optional):** download **`cosmic-nightlight-0.5.2.flatpak`** and run `flatpak install --user ./cosmic-nightlight-0.5.2.flatpak`. It asks for your password once, the first time you turn it on. The `.deb` is still the recommended install until the app is in the COSMIC Store.
