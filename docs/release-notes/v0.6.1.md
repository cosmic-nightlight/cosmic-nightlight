A small update to how Night Light describes itself. The app works the same as 0.6.0.

### Other
- **Clearer store page.** It now says Night Light is an unofficial app, not made by System76, and that it works on COSMIC where most night light apps don't yet.

**Full changelog:** https://github.com/cosmic-nightlight/cosmic-nightlight/compare/v0.6.0...v0.6.1

## Install

1. Download **`cosmic-nightlight_0.6.1-1_amd64.deb`** from the Assets section below.
2. Open it with the **COSMIC Store** and click **Install**
   (or run `sudo apt install ./cosmic-nightlight_0.6.1-1_amd64.deb`).
3. Add the applet: **COSMIC Settings → Desktop → Panel** (or **Dock**) **→ Configure applets → Add applet → Night Light**.

**On Fedora, Arch Linux or NixOS, or want the Flatpak?** See the [install steps in the README](https://github.com/cosmic-nightlight/cosmic-nightlight/blob/v0.6.1/README.md#install).
