Night Light now changes your screen without the flicker.

### New
- **No more flicker.** Turning Night Light on or off, moving a slider, or a scheduled change at sunset used to blink the screen for a second or two. Now the color just changes. If your system can't do it the new way, Night Light changes the screen the old way, as before.

> **If you use the Flatpak,** the first change after updating asks for your password once. That replaces the small helper on your system with the new one.

**Full changelog:** https://github.com/cosmic-nightlight/cosmic-nightlight/compare/v0.6.1...v0.7.0

## Install

1. Download **`cosmic-nightlight_0.7.0-1_amd64.deb`** from the Assets section below.
2. Open it with the **COSMIC Store** and click **Install**
   (or run `sudo apt install ./cosmic-nightlight_0.7.0-1_amd64.deb`).
3. Add the applet: **COSMIC Settings → Desktop → Panel** (or **Dock**) **→ Configure applets → Add applet → Night Light**.

**On Fedora, Arch Linux or NixOS, or want the Flatpak?** See the [install steps in the README](https://github.com/cosmic-nightlight/cosmic-nightlight/blob/v0.7.0/README.md#install).
