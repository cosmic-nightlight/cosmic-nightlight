Night Light now changes your screen smoothly, without the flicker.

### New
- **No more flicker.** Night Light changes no longer blink the screen on most systems. (Thank you to @schrock for testing in #46.)
- Changes fade in and out instead of jumping.
- The screen updates live as you drag the sliders.
- The warmth slider goes warmer and the brightness slider goes dimmer.

### Fixed
- Uninstalling no longer leaves the tint on.
- Logging out and back in no longer loses the tint.
- Toggling Night Light quickly no longer leaves it flipping on and off afterwards.
- Arrow keys and Ctrl+scroll on a slider now save the change.

### Other
- The package is now called `cosmic-ext-nightlight`. It replaces the old one and keeps your settings, panel icon, dock pin and shortcut.

> **If you're upgrading from 0.6.1:**
> - With the Flatpak, open Night Light Settings once. It moves your settings over. The first time you turn Night Light on or off, it asks for your password to remove the old version.
> - On Arch, type `y` when `pacman -U` asks to remove `cosmic-nightlight`. Pressing Enter cancels.

**Full changelog:** https://github.com/cosmic-nightlight/cosmic-nightlight/compare/v0.6.1...v0.7.0

## Install

1. Download **`cosmic-ext-nightlight_0.7.0-1_amd64.deb`** from the Assets section below.
2. Open it with the **COSMIC Store** and click **Install**
   (or run `sudo apt install ./cosmic-ext-nightlight_0.7.0-1_amd64.deb`).
3. Add the applet: **COSMIC Settings → Desktop → Panel** (or **Dock**) **→ Configure applets → Add applet → Night Light**.

**On Fedora, Arch Linux or NixOS, or want the Flatpak?** See the [install steps in the README](https://github.com/cosmic-nightlight/cosmic-nightlight/blob/v0.7.0/README.md#install).
