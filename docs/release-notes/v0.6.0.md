This release fixes a handful of bugs, including two with the screen and one with Bluetooth, and makes it easier to get your schedule running.

### Fixed
- **The screen could stay on after going to sleep.** A scheduled change that came while the display was asleep woke it up, and it stayed lit until you touched the keyboard or mouse. Now the change waits until the display is back on. (Thanks to @kbialek in #10.)
- **The screen flickered twice** when you turned Night Light on or off with both the applet and the settings window open. It now changes once. (#12)
- **Night Light could ignore you after switching to the Flatpak.** If the old applet was still on your panel, turning Night Light on or off sometimes did nothing. Both now take turns, so every change goes through.
- **Bluetooth headphones no longer disconnect** when Night Light changes. They go quiet for a moment while the screen flickers, then carry on. (Thanks to @KaKi87 in #9.)
- **No more password prompts at sunset for accounts that aren't administrators.** The schedule waits instead, and changes you make yourself still ask as before. (#32)
- **The .deb could install without everything it needs.** On some Debian and Ubuntu systems Night Light then couldn't change the screen. (#28)
- **A schedule picked during the Flatpak's one-time setup could be lost** if you changed another setting while the password prompt was open. (#31)

### New
- **Packages for Fedora, Arch Linux and NixOS.** Each release now includes a `.rpm` for Fedora 44 or newer, next to the `.deb`. Arch Linux users can build a package themselves, and NixOS users can add it to their system as a flake. Neither is on the release page, so see the [README](https://github.com/cosmic-nightlight/cosmic-nightlight/blob/v0.6.0/README.md#install) for how. (Thanks to @abu-matterize for the Fedora package in #11, and to @gschurck and @nicolasdumitru, whose NixOS versions inspired this one.)
- **Add to Panel now adds the applet for you.** The button in the "Your schedule isn't running" notice puts Night Light on your panel in one click, instead of sending you to COSMIC Settings to do it.
- **The settings window notices the applet right away.** When you add or remove Night Light from your panel, the "Your schedule isn't running" notice now appears or goes away at once, instead of up to 15 seconds later.
- **Uninstalling the flatpak now cleans up after itself.** The small helper it installs on your system is removed a few seconds after you uninstall the app, so you no longer need to run anything yourself.
- **Turn it on and off with a keyboard shortcut.** Click **Add** next to **Keyboard Shortcut** in Settings, and Super+Shift+N toggles Night Light. You can change the key in COSMIC Settings.

> **If you set up the flatpak with an earlier version,** that helper stays behind when you uninstall. See the [README](https://github.com/cosmic-nightlight/cosmic-nightlight/blob/v0.6.0/README.md#try-the-flatpak-build) for the one command that removes it.

**Full changelog:** https://github.com/cosmic-nightlight/cosmic-nightlight/compare/v0.5.1...v0.6.0

## Install

1. Download **`cosmic-nightlight_0.6.0-1_amd64.deb`** from the Assets section below.
2. Open it with the **COSMIC Store** and click **Install**
   (or run `sudo apt install ./cosmic-nightlight_0.6.0-1_amd64.deb`).
3. Add the applet: **COSMIC Settings → Desktop → Panel** (or **Dock**) **→ Configure applets → Add applet → Night Light**.

**Fedora:** download **`cosmic-nightlight-0.6.0-1.fc44.x86_64.rpm`** and run `sudo dnf install ./cosmic-nightlight-0.6.0-1.fc44.x86_64.rpm`. Then add the applet as in step 3.

**Arch Linux:** there's no download here. Build it yourself as shown in the [README](https://github.com/cosmic-nightlight/cosmic-nightlight/blob/v0.6.0/README.md#install).

**NixOS:** there's no download here either. Add the flake to your configuration as shown in the [README](https://github.com/cosmic-nightlight/cosmic-nightlight/blob/v0.6.0/README.md#install).

**Flatpak (optional):** download **`cosmic-nightlight-0.6.0.flatpak`** and run `flatpak install --user ./cosmic-nightlight-0.6.0.flatpak`. It asks for your password once, the first time you turn it on. The `.deb` is still the recommended install until the app is in the COSMIC Store.
