This release is a minor bug fix update, and adds the groundwork for translating the app into other languages.

### Fixed
- **Repeated password prompts on Fedora Atomic.** Setup said it worked, but every tint change still asked for a password, including the automatic ones at login and after resume. ([Details](https://github.com/cosmic-nightlight/cosmic-nightlight/blob/v0.5.1/docs/fedora-atomic-password-prompts.md). Reported by @sebag90 in #8.)
  > **If you're upgrading on Atomic,** reinstall the host rule with one command. Updating the flatpak doesn't replace it. See [the instructions](https://github.com/cosmic-nightlight/cosmic-nightlight/blob/v0.5.1/flatpak/README.md#repeated-password-prompts-on-fedora-atomic).
- **Brightness changes no longer get lost.** Moving the brightness and temperature sliders at the same time could leave the screen at the old brightness until the next temperature change.

### New
- **The app can be translated.** Adding a language takes one text file and no coding. Partial translations work, with anything missing shown in English. English is the only language so far, so nothing on screen changes yet. See [docs/translating.md](https://github.com/cosmic-nightlight/cosmic-nightlight/blob/v0.5.1/docs/translating.md).

**Full changelog:** https://github.com/cosmic-nightlight/cosmic-nightlight/compare/v0.5.0...v0.5.1

## Install

1. Download **`cosmic-nightlight_0.5.1-1_amd64.deb`** from the Assets section below.
2. Open it with the **COSMIC Store** and click **Install**
   (or run `sudo apt install ./cosmic-nightlight_0.5.1-1_amd64.deb`).
3. Add the applet: **COSMIC Settings → Desktop → Panel** (or **Dock**) **→ Configure applets → Add applet → Night Light**.

**Flatpak (optional):** download **`cosmic-nightlight-0.5.1.flatpak`** and run `flatpak install --user ./cosmic-nightlight-0.5.1.flatpak`. It asks for your password once, the first time you turn it on. The `.deb` is still the recommended install until the app is in the COSMIC Store.
