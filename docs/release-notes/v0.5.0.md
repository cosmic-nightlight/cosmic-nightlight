The schedule can now follow the real sunset and sunrise, and the app can be built as a flatpak, which is the first step toward a COSMIC Store listing.

> ℹ️ **Nothing changes if you use the `.deb`.** It installs everything it needs as before. The flatpak notes below only apply to the sandboxed build.

### New
- **Sunset to Sunrise.** A new schedule option that needs no setup. The tint starts at sunset and lifts at sunrise where you are, and shifts with the seasons. Your location comes from your time zone, so there's no location service, network lookup or coordinates to enter. If it can't work out the sun times, it falls back to your From/To times and tells you why.
- **Flatpak support.** A sandboxed app can't change the screen's colors itself, so the flatpak uses a small helper on your system to do it. ([Why it works this way](https://github.com/cosmic-nightlight/cosmic-nightlight/blob/v0.5.0/docs/flatpak-design.md))
- **Sets itself up on first use.** The first time you turn it on, the flatpak installs that helper for you. You enter your password once, and never again.
- **A settings row when setup is needed.** It appears only if you dismissed the first password prompt or the helper needs updating, and goes away once that's done.
- **Warns when nothing is running your schedule.** Without the applet on your panel, the schedule stopped as soon as you closed the settings window, with no explanation. The settings window now tells you and offers two fixes: add the applet, or run it in the background.
- **Run in Background.** Keeps your schedule running without the applet on your panel. It starts right away and at every login. It disappears by itself if you add the applet back.
- **Temperature slider now goes the intuitive way.** Dragging right makes the screen warmer, with **Less warm** and **More warm** labels at each end. It used to be the other way around.
- **Follows your theme.** The popup and settings window match your theme's styling, including frosted glass.
- **App icon and software center info.** The app now has its own icon and shows up properly in software centers.

### Fixed
- **Only one password prompt at a time.** With both the applet and settings window open, you could get asked twice. Cancelling a prompt could also be followed by several more. Now one "no" means no.
- **No surprise password prompts.** The app no longer shows a password prompt at sunset or after resume on a system that hasn't been set up. It only asks when you change something.
- **Applet and settings window no longer fight over the tint.**
- **Uninstalling removes everything,** including a flatpak install and the panel applet, and resets the screen tint.
- The flicker warning now appears in the settings window too, not just the popup.

**Full changelog:** https://github.com/cosmic-nightlight/cosmic-nightlight/compare/v0.4.0...v0.5.0

## Install

1. Download **`cosmic-nightlight_0.5.0-1_amd64.deb`** from the Assets section below.
2. Open it with the **COSMIC Store** and click **Install**
   (or run `sudo apt install ./cosmic-nightlight_0.5.0-1_amd64.deb`).
3. Add the applet: **COSMIC Settings → Desktop → Panel** (or **Dock**) **→ Configure applets → Add applet → Night Light**.
